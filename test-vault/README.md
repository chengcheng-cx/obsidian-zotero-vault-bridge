# Zotero Bridge Development Vault

Open this folder as a separate Obsidian Vault for manual testing.

```text
01_Papers/       user-supplied PDF fixtures; ignored by Git
02_Literature/   reserved for Milestone 2 output
03_Notes/        user knowledge notes
04_Drafts/       draft writing
Templates/       Literature Note template
```

Never use copyrighted PDFs as committed fixtures. Copy your own normal and difficult test PDFs into `01_Papers/` after cloning.
